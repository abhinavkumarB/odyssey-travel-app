# 🌍 Odyssey — Intelligent Travel Canvas

> A modern, responsive travel exploration platform built with React, Vite, Tailwind CSS, and Google Gemini AI. Features location-aware atmospheric telemetry, progressive media loading, and deterministic AI-driven multi-day itinerary generation.

## 🌟 Key Highlights

- **Cinematic Video Hero:** Progressive media pipeline featuring instant poster rendering, smooth cross-fades, and native OS `prefers-reduced-motion` compliance with play/pause controls.
- **Location-Aware Weather Telemetry:** Real-time atmospheric metrics powered by Open-Meteo with zero API key exposure and a graceful fallback to featured hubs when browser geolocation permission is denied.
- **Debounced Destination Explorer:** High-performance search and categorized exploration with 60fps micro-interactions and layout animations.
- **Deterministic AI Itinerary Engine:** Transforms LLM responses into structured, modular UI components (Day Tabs, Timelines, Activity Badges) backed by a resilient local fallback generator.
- **Conversational Concierge Drawer:** Slide-over assistant aware of active destinations to handle travel queries in real time.
- **Defensive UI Engineering:** Handles offline states with automatic network recovery banners, image loading skeletons, and accessible keyboard focus traps.
